# Private Release Gate

Before any major CekValuasi release:
- engine regression clean;
- no unexplained valuation distribution shift;
- data provenance/freshness acceptable;
- P0/P1 publication issues closed;
- representative ticker forensic sample reviewed;
- mobile reader journey reviewed;
- SEO canonical/sitemap parity clean;
- rollback artifact/reference known;
- monetization cannot influence research output.

Release decision must be evidence-based and reversible.
