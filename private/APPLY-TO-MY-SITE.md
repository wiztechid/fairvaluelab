# Apply Private Moat to CekValuasi

Adoption is staged:
1. Preserve current production.
2. Establish governance and baseline.
3. Add report-only validators.
4. Build new CekValuasi presentation separately.
5. Compare against existing output.
6. Promote only after publication gate.
7. Retain rollback.

Never copy a generic rule over a functioning financial control without checking its effect on the valuation pipeline.
