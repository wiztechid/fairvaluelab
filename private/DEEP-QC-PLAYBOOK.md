# Deep QC Playbook — CekValuasi

For any material release inspect:
1. Input provenance and units.
2. Financial-period alignment.
3. Corporate-action/share-count anomalies.
4. Model eligibility by sector.
5. Bear/base/bull ordering.
6. Method outliers.
7. Family consensus and spread.
8. Extreme market divergence.
9. Confidence/status correctness.
10. Snapshot/PIT integrity.
11. Public JSON parity.
12. Reader-facing explanation.
13. Canonical/indexation.
14. Mobile/accessibility.
15. Monetization separation.

QC must search for ways the system can be wrong, not merely confirm expected output.
