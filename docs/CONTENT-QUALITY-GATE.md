# Content Quality Gate

For financial pages, content quality includes numerical integrity.

A page passes only if:
- ticker/company identity is correct;
- visible numbers match canonical data;
- status/confidence language matches engine state;
- source/freshness context is available;
- methodology/limitations are reachable;
- no unsupported investment promise appears;
- the page adds ticker-specific value;
- internal links point to relevant canonical destinations.

Failing pages must not be promoted merely to increase page count.
