# Governance Adoption

Mode: ADDITIVE / NON-DESTRUCTIVE.

## Adoption sequence
1. Inventory existing production assets.
2. Add governance documents without replacing existing files.
3. Record current state and unresolved risks.
4. Introduce validators in report-only mode first.
5. Resolve false positives.
6. Only then consider enforcement.
7. Any production migration requires separate approval.

Existing FairValueLab engine/frontend/workflows remain authoritative until explicitly promoted through a migration gate.
