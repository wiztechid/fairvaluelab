# Private Moat Boundary

This repository is public. Confidential operating playbooks, proprietary research heuristics, private scoring logic, and reusable private-moat documents must not be committed here.

Only public-safe governance contracts belong in this repository.

Private moat material should remain in a genuinely private storage/repository and may inform implementation without being copied into public history.

A directory named private/ inside a public Git repository is not confidential.
