# CekValuasi Publication Gate

No new public page is eligible for indexable publication until all applicable gates pass.

## Gate 0 — SERP Opportunity
Before drafting:
- define the exact user query/task and search intent;
- inspect the live SERP or equivalent current evidence;
- identify what existing results already solve well;
- state the specific information/tool gap CekValuasi can improve;
- record whether the page is acquisition, supporting, product/tool, reference, or ticker content.

A keyword alone is not an opportunity. If no meaningful gap or product fit exists, do not publish.

## Gate 1 — Intent owner
- assign one canonical URL and one primary intent owner;
- map secondary/supporting queries to that owner;
- verify the proposed page is not merely a synonym/permutation of an existing owner;
- register approved launch URLs in the SEO Opportunity Map.

## Gate 2 — Cannibalization
Compare the candidate against existing and planned pages:
- same user task?
- same expected answer?
- substantially overlapping SERP?
- same product bridge?

If materially the same, merge into the existing owner by default. Separate only when evidence shows distinct intent and the reader benefits from separation.

## Gate 3 — Reader-first quality
The Content Quality Gate must pass. The page must answer the query efficiently, show evidence/limitations where material, and add original value. No word-count padding, mass-template prose, fake comprehensiveness, or unsupported investment claims.

## Gate 4 — Product bridge
Define the natural next decision:
- Discovery → Scanner / Fair Value
- Valuation → Fair Value / relevant interpretation
- Risk → QSTP

The bridge must help the reader continue the task. A page must not exist solely as a doorway to a product.

## Gate 5 — Technical SEO
Before indexation:
- unique and accurate title/H1/meta;
- self-consistent canonical;
- correct robots state;
- structured data matches visible content;
- relevant internal inbound/outbound links exist;
- sitemap eligibility is correct;
- mobile rendering and accessibility are acceptable.

## Gate 6 — Financial/data integrity (when applicable)
- canonical numbers and identities match source data;
- provenance/freshness are known;
- status/confidence language matches engine state;
- no fabricated value for insufficient evidence;
- PIT PROVISIONAL vs VERIFIED distinction is preserved where relevant.

## Gate 7 — Publication decision
PASS only when all applicable gates pass. Otherwise:
- HOLD for remediable gaps;
- MERGE when another intent owner already exists;
- REJECT when opportunity/product fit is insufficient;
- NOINDEX when a useful user state should exist but should not compete in search.

## Post-publication review
Monitor whether the page:
- receives impressions for its intended query family;
- begins competing with another CekValuasi owner;
- sends readers to the expected next decision;
- becomes stale or loses evidence quality.

Update, merge, redirect, noindex, or retire when evidence warrants it. Never keep weak pages solely to preserve page count.

## Existing valuation-engine gates
Generated ticker/valuation pages additionally remain subject to run, valuation, data, historical/PIT, and public-page integrity contracts defined by the valuation governance documents.

## Anti-content-farm invariant
Scaling is allowed only as repeated proof of usefulness:
SERP Opportunity → Intent Owner → Cannibalization → Reader-First → Product Bridge → Technical/Data Integrity → Publish.

No batch may bypass these gates because of publishing targets, keyword count, automation convenience, or monetization pressure.
