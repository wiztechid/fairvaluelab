# Content Lifecycle

States: DRAFT → REVIEW → PUBLISHED → REFRESH_DUE → UPDATED / RETIRED.

For ticker pages, lifecycle is coupled to data freshness but not identical to it. A page may remain structurally valid while its valuation is STALE; the UI must show that state instead of pretending the analysis is current.

Refresh triggers include new financial reporting period, material corporate action, universe eligibility change, model-version change, or material source correction.
