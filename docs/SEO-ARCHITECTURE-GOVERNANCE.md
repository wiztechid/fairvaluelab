# SEO Architecture Governance — CekValuasi

## Intended architecture
/ — search/brand home
/saham/{ticker}/ — canonical ticker valuation report
/sektor/{slug}/ — useful sector discovery/analysis hubs
/metodologi/ — methodology and limitations

## Indexation rules
Index only pages with substantive, current, internally consistent content. Error, empty, duplicate, and thin states must not become indexable inventory.

## Programmatic SEO guard
Ticker pages must expose genuine ticker-specific data/evidence. Template uniqueness alone is not content value.

## Canonical rules
Exactly one canonical URL per public entity/page intent. Query-string research views must not compete with permanent ticker pages after migration.

## Sitemap gate
Only canonical indexable URLs. Sitemap, canonical, internal links, and actual HTTP destination must agree.
