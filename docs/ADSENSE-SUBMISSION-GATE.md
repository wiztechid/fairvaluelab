# AdSense Submission Gate

This is a future gate; it does not authorize AdSense installation.

Before submission:
- canonical domain migration is complete;
- privacy/about/contact/disclaimer/terms coverage is complete;
- robots and sitemap match production canonicals;
- no mass thin ticker inventory is indexable;
- methodology and financial limitations are visible;
- navigation and mobile UX are stable;
- no broken/error-generated pages are promoted;
- consent/CMP requirements are implemented where applicable;
- ad placements are separated from valuation actions.

Submit only after the public product, not merely the repository, passes the gate.
